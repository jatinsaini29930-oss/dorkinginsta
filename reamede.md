# DorkForge 🔎

DorkForge is a lightweight command-line search-query generator for
authorized security auditing and OSINT research.

It generates search-engine queries using operators such as:

- site:
- filetype:
- inurl:
- intitle:
- keyword filters

## Features

- Interactive CLI
- Custom domain
- Query categories
- Custom keywords
- Duplicate removal
- `.txt` export
- No external Python dependencies
- Linux / macOS / Windows compatible

## Disclaimer

Use DorkForge only on domains and information that you own or are
explicitly authorized to assess.

DorkForge does not:

- exploit vulnerabilities
- brute-force accounts
- collect passwords
- bypass authentication
- scan ports
- attack websites
- automatically download discovered files

The tool only generates search queries.
